# VOXA

Une voix. Toutes les IA. Toutes les actions.

Prototype fonctionnel de l’expérience VOXA en React, TypeScript, Vite, Motion et Lucide. La vidéo Flow fournie est locale dans `public/media/halo-hero.mp4` : elle ne dépend pas d’un lien temporaire.

## Lancer

```bash
npm install
npm run dev
npm run build
```

## Fonctionnalités actuelles

- landing responsive 320–1920 px ;
- Hero vidéo Flow avec poster ;
- thème noir/violet, mode clair et couleurs d’accent personnalisables ;
- navigation mobile ;
- HALO et visualisation de ses états ;
- démonstration dans un cadre MacBook ;
- champ de commande, suggestions, plan et confirmation ;
- FAQ honnête sur les limites d’une PWA ;
- manifeste PWA et cache de base hors connexion ;
- respect de `prefers-reduced-motion`.

Les actions du panneau de démonstration sont explicitement présentées comme une scène marketing. Les actions IA réelles, le BYOK et les connecteurs seront ajoutés dans les écrans applicatifs suivants.
